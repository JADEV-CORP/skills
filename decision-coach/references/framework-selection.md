# Framework selection

Pick the two or three frameworks that fit the case, never more. Name each with its source book. The full frameworks are in `mental-models.md`.

| Situation | Frameworks (source book) |
|---|---|
| Choosing between paths | Decision method (`decision-method.md`), then BATNA (Getting to Yes), pre-mortem and outside view (Thinking, Fast and Slow), opportunity cost (The Intelligent Investor) |
| Writing to clients | StoryBrand (Building a StoryBrand), Cialdini (Influence), SPIN questions (SPIN Selling) |
| Designing a system | Dependency Rule (Clean Architecture), architecture characteristics (Fundamentals of Software Architecture), bounded contexts (Domain-Driven Design) |
| Building a product | Build-Measure-Learn (The Lean Startup), smallest viable audience (This Is Marketing), 0-to-1 test (Zero to One) |
| Scaling | Flywheel (Good to Great), data-intensive patterns (Designing Data-Intensive Applications), monopoly theory (Zero to One) |
| Negotiating | Tactical empathy and calibrated questions (Never Split the Difference), BATNA (Getting to Yes), Cialdini (Influence) |
| Reviewing code | SOLID and the Dependency Rule (Clean Architecture), Effective Java or C# in Depth patterns, naming and functions (Clean Code) |
| Defining a roadmap | Fitness functions (Fundamentals of Software Architecture), saga styles (Microservices Patterns), storage patterns (Designing Data-Intensive Applications) |
| Delivery and release pipelines | Build once and promote the same artifact (Continuous Delivery), fitness functions, reliability under faults (Designing Data-Intensive Applications) |
| Habits and routines | Habit stacking (Atomic Habits), time blocking (Deep Work), growth mindset (Mindset) |
| Pricing and money | Margin of safety (The Intelligent Investor), cash flow (Financial Intelligence), innovation accounting (The Lean Startup) |
| Presenting or pitching | Hook patterns (`hook-structures.md`), SB7 (Building a StoryBrand), SUCCESs (Made to Stick) |

Domain defaults that always apply:

- **Self-development:** identity-based habits (Atomic Habits) and deep work (Deep Work), not generic motivation.
- **Finance:** margin of safety (The Intelligent Investor) and cash flow (Financial Intelligence), not abstract caution.
